# Lecture Scanner

Локальное приложение для пакетной обработки фотографий лекций: обнаружение области слайда, OCR, проверка качества, организация распознанного текста и экспорт в DOCX / Markdown / TXT.

**Приватность:** по умолчанию приложение работает локально. Фотографии, база и результаты сохраняются на компьютере пользователя в `app_data/`. Не загружайте личные фотографии, базу или OCR-результаты в публичный репозиторий.

## Возможности

- пакетное добавление фотографий из локальной папки;
- обнаружение основного экрана и fallback на распознавание всей фотографии;
- сохранение исходного OCR и отдельных вариантов обработки;
- очередь обработки с возможностью продолжить после остановки;
- контроль качества и повторная обработка слабых результатов;
- тематическая группировка и экспорт в DOCX, Markdown и TXT.

## Требования

- Python 3.10–3.13 (рекомендуется Python 3.11 или 3.12 для совместимости OCR-зависимостей);
- macOS, Windows или Linux;
- для OCR потребуется установить зависимости из `requirements.txt`.

## Установка

### macOS / Linux

```bash
git clone <URL-ВАШЕГО-РЕПОЗИТОРИЯ>
cd LectureScanner
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
streamlit run app.py --server.address 127.0.0.1 --server.port 8501
```

### Windows (PowerShell)

```powershell
git clone <URL-ВАШЕГО-РЕПОЗИТОРИЯ>
cd LectureScanner
py -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
streamlit run app.py --server.address 127.0.0.1 --server.port 8501
```

Откройте `http://127.0.0.1:8501`. OCR запускается вручную из интерфейса.

## Использование

1. Выберите папку с фотографиями лекции.
2. Просмотрите список и подтвердите порядок фотографий.
3. Запустите обработку. Приложение сохраняет промежуточные результаты и позволяет продолжить очередь.
4. Откройте вкладку результатов и скачайте нужный формат.

Путь к исходной папке можно задать переменной окружения `LECTURE_SCANNER_INPUT_DIR`. Путь к данным приложения — `LECTURE_SCANNER_DATA_DIR`. Это удобно для отдельных профилей и тестов.

## Локальные данные и безопасность

Следующие данные не должны попадать в публичный Git-репозиторий:

- `app_data/` и файлы базы данных;
- исходные фотографии и сканы пользователей;
- JSON/TXT/DOCX с распознанным содержимым;
- `.venv/`, кэши и системные файлы;
- API-ключи, токены и пароли.

`.gitignore` уже исключает основные локальные каталоги. Перед публикацией проверьте `git status` и историю коммитов: `.gitignore` не удаляет файлы, которые уже были закоммичены.
